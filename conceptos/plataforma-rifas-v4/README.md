# Concepto V4 — Negro y naranja neón

Versión de demostración de la **plataforma de rifas (marca pendiente)**, pensada para la experiencia visual de un cliente final.

## Diseño
- Fondo negro y halos cálidos en naranja.
- Botones transparentes sin bordes sólidos; línea inferior naranja con brillo al interactuar.
- Tarjetas de premios oscuras, progreso naranja, números seleccionables con neón.
- Diseño responsivo para computador y celular.

## Probar
Abre [index.html](./index.html) en un navegador. Está autocontenido: incluye HTML, CSS, JavaScript e ilustraciones SVG.

## Alcance de demo
Catálogo ficticio, filtros, premios, selección de números y resumen simulado. Los datos, precios y fechas son de **demostración**.

**No es una plataforma autorizada para operar rifas.** No procesa pagos, no asigna boletas legales ni tiene inventario transaccional, autenticación o backend de producción.

Para continuar el desarrollo se deben implementar servicios seguros, permisos, catálogo real, reservas atómicas, conciliación y validaciones regulatorias aplicables.
