# Concepto visual V2 — Plataforma de Rifas

**Nombre comercial pendiente.** Este concepto no adopta ni modifica la marca existente del repositorio.

## Vista previa

Abrir `index.html` en el navegador (archivo autónomo con CSS, JS y recursos de respaldo integrados). Ruta: `conceptos/plataforma-rifas-v2/index.html`.

## Diseño nuevo

- Estilo profesional de alto contraste: negro grafito, naranja eléctrico y tipografía de gran impacto.
- Botones sólidos, rectangulares, con estados hover/focus visibles.
- Hero con premio destacado, galería y catálogo responsive.
- Panel administrativo con indicadores, listado y creación de borradores.

## Funciones demostrativas

- Navegación entre inicio, catálogo, detalle de cada premio y panel administrativo.
- Filtros por categoría y selección visual de números (simulada).
- Guardado local de borradores; no existe una base de datos compartida.
- Tres premios ficticios para probar el diseño.

## Seguridad y regulaciones

**Únicamente prototipo. No hay rifas autorizadas, pagos, boletas reales, asignaciones oficiales ni autenticación.**

No agregar credenciales al código público. Para comercializar, se requerirá backend transaccional, control de números concurrentes, pagos y conciliación, validación regulatoria, autorización y certificaciones aplicables.

## Trabajo posterior

1. Convertir este concepto en componentes reutilizables del frontend aprobado.
2. Incorporar identidad de marca cuando se defina.
3. Implementar autenticación, roles y backend seguro.
4. Pruebas accesibles en móvil, concurrencia y recuperación ante errores.
